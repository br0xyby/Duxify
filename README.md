# Duxify

A Firebase and Accessibility Service powered remote Android application control system.

## Features

* Firebase Realtime Database integration
* List all applications
* Bulk blocking
* Instant access granting
* Real-time monitoring via Accessibility Service
* Mode persistence with SharedPreferences
* 100% Kotlin

## Technologies

Kotlin, Android SDK, Firebase, Accessibility Service

## Installation

1. Clone the repository
2. Create a Firebase project
3. Download `google-services.json`
4. Open in Android Studio
5. Run
